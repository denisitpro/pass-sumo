### Info (no action implied)

- **Memory leaks: none found.** No Combine, no KVO, no event monitors, no AppKit bridges; both
  `Timer`s use `[weak self]` and self-invalidate; the one security-scope bracket is `defer`-balanced;
  every `z_stream` and `CCCryptorRef` in the vendored library is released in `deinit`/`defer`;
  the `save()` task chain releases itself on completion.
- **Buffer overflows: none found.** Every TLV parser goes through the bounds-checked `ByteCursor`;
  decompression is capped at 256 MiB before allocation; HMAC blocks are authenticated before use;
  XXE is disabled; TOTP truncation offsets are in range for all three hashes; the password
  generator uses `SecRandomCopyBytes` with rejection sampling and a Fisher–Yates shuffle.
- **Secret residency, by design:** the master password lives as a Swift `String` in
  `VaultStore.credentials` for the whole unlocked session; the vendored `SecureBytes.init` copies
  its source through an unscrubbed heap array (documented upstream caveat; `Argon2KDF.swift:69`
  passes an `UnsafeBufferPointer`, which always allocates); TOTP secrets are plain `[UInt8]`.
  `SecureBytes` is used only on the keychain hop. The `mlock`'d arena pins ≥64 KiB for the process
  lifetime once used.
- **Dependencies are current.** Every claim in `docs/dependency-currency.md` (2026-09-10)
  re-verified identical on 2026-09-13: KDBXKit pin is upstream `develop` HEAD, Argon2 pin is
  upstream HEAD, all SwiftPM pins are at their latest release except `swift-crypto` 3.15.1 (4.5.2
  current; major bump deferred to #23, no reachable advisory). XcodeGen 2.46.0 and KeePassXC
  2.7.12 are latest. SDK zlib is 1.2.12.
- **CI is deliberately off.** `.github/workflows/ci.yml` was renamed to `ci.yml.d` in `6e2bcb6`
  (2026-08-30); GitHub registers only the Dependabot workflow. The `keepassxc-cli` round trip
  therefore runs only locally via `make durability`.
- **Search includes the password field** (`Domain.swift:901`). Deliberate, documented and tested
  differentiator; not a defect.
- **Not implemented, and not claimed anywhere:** master-password change, key-file UI,
  passphrase/diceware generator, Recycle Bin auto-purge, Lock All tabs, `fsync` before rename
  (recorded in `Sources/DurabilityTests/README.md:156`).
- **Verified correct and well tested:** save chain and `editRevision`; backup retention and
  failure surfacing; KDBX merge (tombstones, `LocationChanged`, history caps, append-only pool);
  TOTP against RFC 6238 vectors for SHA1/256/512; attachment size checks before read; tab
  identity and close prompt; biometric policy and `LAError` mapping; recycle-bin deletion guards.
